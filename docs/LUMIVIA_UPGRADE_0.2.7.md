# Lumivia 0.2.7 升级说明

从 Fork main 的 `10923db503ae34a35945409c4b4c97e6124a6e68` 合并官方稳定标签
`v0.2.7`（`aea725f2ea644d5592d0bbb1d63b607efa7e200a`），不包含标签之后的开发提交。
官方标签内 VERSION 尚为 0.2.5；本 Fork 显式同步为 0.2.7，以便镜像显示实际发布版本。

## 行为与定制

纳入 Seedance 原生视频任务接口、插件宿主服务与只读状态通道，以及 Gemini 流式、
Kimi 配额暂停、Codex 工具 schema 和 DeepSeek 思考模式等官方修复。

保留手动周限额扣时重置、每订阅自动扣时开关、手动月额度扣时重置、周/月窗口联动、
事务行锁、预览冲突保护、日窗口保留、缓存失效、紧凑订阅控件及 Fork 更新来源。
休闲中心是独立服务，本次不替换其镜像或源码。

合并冲突仅涉及 docs 忽略例外与渠道监控测试提供商数量。两份文档例外均保留；
数量断言继续使用 PROVIDERS.length，保留 Grok 与布局断言。发布流水线继续运行
Lumivia 专项回归、前端构建和上游 CI。

## 从线上 0.2.4 升级

生产仍为 `13e4ee4c6134e93eabc1d5ef9ca9a69b27c35fac`，因此本次包含此前只发布到仓库的
0.2.5 变更。SQL 差异只有两份 238 迁移：

- `238_opencode_go_platform.sql`：平台约束增加 OpenCode，原值保留。
- `238_purge_unlimited_user_platform_quotas.sql`：清理日/周/月限额均为 NULL 的无限额平台行。
  不存在的行表示不限额。这些行的历史周期用量也会删除，因此升级前必须保留完整数据库备份。

迁移框架以完整文件名为键，两份 238 与已执行的定制 235 不冲突。既有迁移文件不得改名或改内容。
本次不修改任何已购买订阅的有效期、额度窗口或自动重置偏好。

## 生产部署与回退

2026-09-21 起生产在 `43.173.94.210` 的 `/opt/sub2api-custom/compose.yml`，使用
nginx 与四服务 Compose。雨云旧 Lumivia 保持停止。仓库旧 `lumivia-update.sh` 要求
`docker-compose.yml` 和 `.env`，不直接适用于当前规范化 Compose；此次以受审查的
部署脚本保存当前配置，仅替换主站固定 SHA 镜像。

正式替换前先预拉镜像并核对 Fork 来源与提交，暂停入口及休闲中心/主站写入，
保留数据库逻辑备份、当前配置、主站数据及 SQLite 一致性副本。先核对数据库迁移和
订阅关键字段，再恢复休闲中心及网站入口。数据库/Redis 镜像及原业务密钥保持。

回退到刚保存的 0.2.4 镜像时，新增平台 CHECK 可保留；无限额平台行不会自动恢复，
且新创建的 OpenCode 配置旧版不支持。上线后已有业务写入时不得直接恢复旧整库。
部署结果、CI 链接、完整镜像 SHA 和备份路径记录在工作区的对应部署文档。
