## 使用记录平均 TPS

用户和管理员使用记录的延迟栏，在首字和总耗时下增加平均 TPS。
口径为输出 Token 数 ÷（总耗时 − 首字耗时），时间单位为秒。
例如输出 230 Token、总耗时 31.27 秒、首字 17.27 秒，显示 16.4 tokens/s。
历史记录具备有效的输出 Token、总耗时和首字耗时即可显示，无需回填数据库。
缺少首字耗时（如部分非流式记录），或扣除后用时不大于零，显示「-」，不估算。
