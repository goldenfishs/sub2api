# 乐米AI / Lumivia 0.2.10

从生产对应的 `3c3f9dc29229d235c68eb16ee75309c3308bae2d` 合并官方稳定标签
`v0.2.10`（`e8cbebf37505922d30ffccd0a5bc19c4beec60ac`），包含 0.2.9 与 0.2.10 的更新。
标签中的 VERSION 为 0.2.9，本 Fork 显式设为 0.2.10，使发布版本与稳定标签一致。

## 更新与定制

上游增加 Claude Sonnet 5.5、Claude 账号原生重置额度状态查询、风控用户白名单，
并修复流式用量、复合分组/WebSocket 路由、工具名改写、账号白名单映射等问题。

保留乐米的周/月额度扣时重置、自动重置开关、窗口联动、预览冲突与行锁保护、
订阅续费和 Fork 更新来源。保留全部智检功能，包括流式生成、600 秒超时、
总计最多 3 次尝试、截断后提高至 16,000 Token、悬停预览、删除和人工质量复核。
休闲中心继续作为独立服务运行。

新增独立模型 `gpt-6.1-sol`，覆盖模型目录、映射预设、Codex/OpenCode 配置导出、
智检模型建议和计费。保留旧 Sol/Astra 的 ID 与默认设置。新模型默认推理档位为
`medium`，可选 `low / medium / high / xhigh / max`；显式 `none / minimal` 返回
参数错误。支持 Responses 工具调用；仅支持 Chat Completions 的上游不接受该模型的
工具调用请求，避免静默丢弃工具。上下文 1,050,000，最大输出 128,000。

按 [OpenAI 官方模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol)
（2026-09-30 核对），每百万 Token 标准价格为输入 $2、缓存读取 $0.10、缓存写入
$2.50、输出 $10；Fast 为 2 倍，输入超过 272,000 时整条请求输入/缓存为 2 倍、
输出为 1.5 倍。目录缺少该模型时使用独立后备价格，已有管理员自定义计价仍优先。
生产模型映射只为上游模型列表已返回此 ID 的账号添加；未返回或查询失败的账号不启用。

## 数据和回退

0.2.8 至 0.2.10 的 migrations 目录完全相同，未增加或改写数据库迁移。
升级只替换主站与智检的一对同提交镜像；生产 Compose 的凭证、卷、环境变量和
数据库、Redis、休闲中心配置沿用原值。先备份，再等待智检空闲后短暂切换。

上游计价修复会影响未来请求：渠道图片输入/输出 Token 价格未配置时，沿用目录中的
图片价格；显式配置为 0 的价格仍保留。账号统计长上下文成本使用账号自身的开关，
独立于分组面向用户的售价开关。本次不重写管理员的价格配置或历史账单。

本版本没有新增 schema 回退障碍，但镜像回退仍有业务兼容条件：新版本允许分组模型
白名单在任意位置使用 `*`，旧版本只支持末尾通配；新风控用户白名单与
`cyber_log_only` / `risk_control_log_only` 审计模式也不受旧版本支持，旧版本可能把
这些仅记录事件计入自动封禁次数。部署脚本在回退前先停止新版本写入，再只读检查：
没有新增不兼容通配规则、风控用户白名单为空、没有上述审计事件，且迁移/订阅结构
和价格配置与切换前相同，才自动恢复旧镜像与 Compose。检查失败或发现障碍时保留
新版本配置并重新启动新镜像，记录原因，转为向前修复；不会删除配置或审计记录强行回退。

回退不会重算升级期间已产生的计费记录。已经产生业务写入后，不得用旧数据库备份
覆盖当前数据库。健康检查通过只说明服务可用，不代表全部计价路径已在生产实测。

## 验证与部署

发布前验证乐米订阅定制、智检桥接、上游流式/计价修复、前端测试与构建，
并执行隔离容器内的智检渲染与持久化检查。测试不调用付费模型。
部署后检查版本、主站/智检健康、公开页面、管理员只读接口、迁移清单和定价配置，
确认数据库、Redis、休闲中心和 CPA 容器未重建。
GPT-6.1 Sol 的验证包含离线模拟上游、独立价格及边界计费、模型目录/配置导出，
上线后再检查模型映射和目录可见性；不以列表可见代替真实推理验证。

具体执行结果见对应 PR、GitHub Actions 和工作区部署记录；本文描述升级范围与要求。
