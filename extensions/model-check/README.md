# Lumivia 模型智检

支持本地预览与可选的独立容器部署。Sub2API 主站提供入口和鉴权桥接，独立智检服务负责调度、生成、隔离渲染与结果保存。仓库发布不自动部署线上；部署配置见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

演示模式使用预设作品；管理员另行保存并启用的任务会按其配置调用模型。

## 已实现

- `/model-check`：无需登录查看管理员公开的质检作品、判定依据、HTML 动画播放与下载。上方按监测任务显示最近 30 次检测的画面通过率、最近总耗时和状态条，可点击记录查看对应结果。
- 作品标注站内 Key 的分组；分组名称由后台 Key 数据获取并随结果保存，换组后不改写旧作品。外部 Key 可填写用于展示的分组名称，未填写时标为外部接口，历史缺失的分组不猜测补填。
- 画面通过率 = 通过 /（通过 + 待复核）；接口或渲染失败单独计数，没有有效判定时显示“—”。统计使用任务当前分组、模型、测试方式和生成参数的最近 30 次完成记录。示例统计与真实监测任务隔离，不填充虚构历史记录。
- 登录后的个人自测：选择自己的乐米 Key，或输入外部 HTTPS Base URL / Key；支持 Responses 与 Chat Completions。结果默认私有，Key 仅在执行期间保存在内存，不落库、不写入浏览器存储。
- `/admin/model-check`：管理员配置 Key、模型、测试方式、推理强度、输出上限、频率、公开状态；手动检测、定时执行、设置基准与前后截图对比。
- 管理员 API：复用系统设置中的全局管理员 API Key，提交一次检测、等待或轮询结果、直接下载 WebP 图片；支持 24 小时请求去重。完整路径、参数与 curl 示例见 [API.md](./API.md)。
- 详情与结果 API 提供 TPS：输出 Token ÷ 生成秒数，含首字等待，不含图片渲染时间；已有用量和耗时的旧记录也可显示，示例与缺失值显示空。
- 管理员和用户都只有「鹈鹕骑行」「随机创作」两种测试方式。鹈鹕使用固定题目；随机创作每轮独立抽取主题、主体、两项元素、场景、动作、风格、配色，按统一规则构思二维循环动画。后端生成提示词，不接受自定义提示词替换。
- 独立 SQLite 保存任务、提示词、随机创作条件、截图、HTML、用量与检查依据。关闭网页后调度继续。重启时不重发未完成的付费请求，改记“服务重启中断”。
- 每个任务 / 每位用户保留最近 30 条，另外保留选定基准；最多 20 个监测任务，全局最多 600 条完成记录（基准除外）。

这是**画面规则初筛**，不是训练过的模型身份或智商分类器。检查分由 SVG 结构、可见内容、采样时的动画变化、屏幕适配四项组成。同提示词、模型和参数下，相对人工选定基准下降至少 20 分时标记待复核。题意、人物细节、画面审美与动作合理性仍要人工对照；简单动画可能得到高分。接口错误不当作“降智”。

## 本地启动

依赖：Node.js 22.22.2+（22.x）、24.15.0+（24.x）或 26+，推荐 Node.js 24；还需可访问的 Sub2API（默认 `http://127.0.0.1:8080`）。登录身份与站内 Key 由 `SUB2API_BACKEND` 指向的 Sub2API 验证。

```sh
# 仓库根目录
cd extensions/model-check
npm ci
npm run install:browser
cd ../../frontend
npm run dev:model-check
```

打开 `http://localhost:3000/model-check`。这个脚本同时启动 8096 智检服务与 3000 Vue 页面，Ctrl+C 结束两者。Vite 显式加载 `vite.config.ts`，避免旧构建产生的同名 `.js` 配置覆盖代理设置。

开发脚本默认开启演示模式：预设离线 SVG 经真实渲染器检查并入库，每份作品清楚标注“本地示例”，用量与生成时长留空，历史不伪造。点击“体验检测流程”同样不会调用模型。示例不能当作真实服务能力结论。

如需自己填写 Key 做真实测试，界面会提示产生 API 费用。自动化测试使用模拟上游响应与离线渲染，不产生模型调用费用。`npm start` 默认不开启演示模式。

## 服务配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `MODEL_CHECK_ENABLED` | `false` | Go 主站开关；启用时注册智检代理并显示导航 |
| `MODEL_CHECK_UPSTREAM` | `http://127.0.0.1:8096` | Go 主站连接智检服务的回环地址 |
| `MODEL_CHECK_BRIDGE_SECRET` | 无 | Go 与智检服务共享的随机秘密，生产启用时至少 32 字节；不要提交到仓库 |
| `MODEL_CHECK_HOST` | `127.0.0.1` | 服务绑定地址；演示模式只接受回环地址 |
| `MODEL_CHECK_PORT` | `8096` | 智检 API 端口 |
| `SUB2API_BACKEND` | `http://127.0.0.1:8080` | 验证登录与读取用户自己的 Key |
| `MODEL_CHECK_SITE_API_BASE` | `http://127.0.0.1:8080/v1` | 乐米 Key 的固定请求地址，由运营方配置 |
| `MODEL_CHECK_DATA_DIR` | 工作目录下 `.data` | SQLite 与加密主密钥；必须一起备份 |
| `MODEL_CHECK_DEMO` | `0` | `1` 开启本地示例，禁止绑定到公网 |
| `VITE_MODEL_CHECK_TARGET` | `http://127.0.0.1:8096` | 本地 Vue 代理目标 |

定时任务的 Key 用 AES-256-GCM 加密，主密钥 `.data/encryption.key` 权限为 0600；`.data/` 已加入 Git 忽略。更改连接地址或 Key 后应重新验证基准，截图不会公开管理员连接地址、Key 或用户身份。

调度采用固定间隔（5–1440 分钟），保存后下一间隔才开始。最多同时执行 2 个任务，同一用户 / 监测任务不能重叠，等待队列总量最多 8；不追补停机期间的任务，不自动重试。当前服务限定单实例运行，避免多实例重复付费调用。

外部接口仅支持公共地址上的 HTTPS 443，不允许内网、回环、链路本地或混合 DNS 地址；连接固定到检查后的解析 IP，不跟随跳转。仅管理员配置的站内 API 地址可以使用本地网络。

## 渲染边界

题目要求单文件 HTML、内联 SVG、CSS / SMIL 动画，不支持 JavaScript、Canvas、外部字体或图片。DOMPurify 清理后在独立短生命周期 Chromium 中渲染，JavaScript 和网络均禁用，桌面 960×600、手机 390×600，采样约 0.18 / 0.83 / 1.56 秒。前端预览使用不带权限的 `sandbox` iframe，并附加严格 CSP。

超出 HTML 大小 / DOM 节点限制的内容不会执行，渲染超时会终止整个子进程组。复杂的长周期动画、低对比画风可能被标记待复核，结论应结合截图判断。渲染环境错误单独记失败。

## 仓库交付与启用

生产镜像默认关闭智检。启用后，Go 主站在现有域名下代理 `/api/v1/model-check/`，无需给 Node 服务单独开放公网端口，也不需要为显示入口重新构建前端。`model_check_enabled` 同时随公开设置 API 与页面初始化数据返回；旧版或未启用的后端不会显示入口。

发布流水线分别构建主站和智检镜像，使用同一个提交号。可选 Compose 覆盖文件为 `deploy/docker-compose.model-check.yml`，包含持久化卷、非 root 运行、资源限制和健康检查；主站与智检服务共享网络命名空间，智检仅监听回环地址。完整步骤和备份要求见 [部署说明](./DEPLOYMENT.md)。

身份桥使用短时签名传递真实客户端 IP、User-Agent 和当前鉴权凭证的绑定信息，保持主站现有会话绑定校验。签名仅允许回环上的指定只读鉴权接口使用，不改变管理员或用户 Key 的权限。管理员 API Key 与桥接秘密都不会发送给模型上游。
